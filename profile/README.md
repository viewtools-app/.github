# viewtools

Small, offline tools for developers. Each one is a single binary that reads local data and never calls the network.

| Tool | What it does |
|---|---|
| [acusage](https://github.com/viewtools-app/acusage) | Token usage and API cost per account for Claude Code, Codex, Antigravity and Gemini CLI. `npx acusage` |

Website: [viewtools.app](https://viewtools.app)
