# ViewTools

Free, privacy-first tools for developers. No uploads, no accounts, no tracking.

| Tool | What it does |
|---|---|
| [viewtools.app](https://www.viewtools.app) | View and inspect HTML, Markdown and JSON in the browser, and compare JSON documents with JSON Diff. |
| [acusage](https://github.com/viewtools-app/acusage) | Token usage and API cost per account for Claude Code, Codex, Antigravity and Gemini CLI. Offline CLI: `npx acusage` |
