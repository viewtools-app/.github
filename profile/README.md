# ViewTools

Free, privacy-first tools for developers. No uploads, no accounts, no tracking.

| Tool | What it does | Try it |
|---|---|---|
| [viewtools.app](https://www.viewtools.app) | View and inspect HTML, Markdown and JSON in the browser; compare JSON with JSON Diff. | [viewtools.app](https://www.viewtools.app) |
| [acusage](https://github.com/viewtools-app/acusage) | Token usage and API cost per account for Claude Code, Codex, Antigravity and Gemini CLI. Offline, read-only CLI. | `npx acusage` · [acusage.viewtools.app](https://acusage.viewtools.app) |
